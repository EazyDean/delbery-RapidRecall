# Silent demonstration shot list

Target length: **90–120 seconds** (maximum allowed: 3 minutes). Record in portrait orientation with
touch indicators enabled. Use short on-screen title cards if extra explanation is needed; do not add
audio.

1. Launch **delbery • RapidRecall** from the Android launcher (5 s).
2. Pause on the start screen so **Start a round**, **Attempt log**, and **Summary** are all visible
   (5 s).
3. Tap **Start a round**, choose **4**, then tap **Begin sequence** (8 s).
4. Let all four digits display one at a time without cuts (6 s).
5. Enter the exact sequence and tap **Check my answer** (8 s).
6. Hold on the correct feedback comparison (5 s), return home, and open **Attempt log** (8 s).
7. Show the successful record, including timestamp, target, answer, and digit count (6 s).
8. Return home, start another round, and choose **6** (8 s).
9. Let all six digits display one at a time; enter a deliberately different sequence (12 s).
10. Hold on the incorrect target/input comparison, then return home (7 s).
11. Open **Summary** and show total attempts, correct attempts, and updated accuracy (8 s).
12. Return home and end the recording (3 s).

Before submission, name the finished recording `RapidRecall-demo.mp4` and place it in this directory.
